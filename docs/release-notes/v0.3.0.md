# mth-plugins 0.3.0

This is a minor version bump and the release that completes the 1.0 parity
milestone. The version stays in the `0.x` range until 1.0 is declared; there is
no major bump here. PyPI publication is a separate maintainer action.

## What shipped

- **Tier 1 parity complete.** The `fs-search-tool` component registers the
  reference `glob` and `grep` tools, closing the last in-scope parity gap. The
  ratification's 12-plugin list is complete.
- **Installed-wheel packaging.** The marketplace `index.json` now ships inside
  the package, and a `magitech.components` entry point advertises the shipped
  catalog to the harness. `mth component discover` and `mth component install`
  work from an installed wheel (harness 0.3.0).
- **Safety fixes proven live.** Approval, sandbox, path confinement, CodeAct
  escape hardening, compaction with a byte-exact pruner, repeat reminders,
  `TOOL_TIMEOUT`, and child-agent policy pinning all have live conformance
  probes.
- **End-to-end validation.** The installed wheels were driven as an end-user;
  every disclosed gap was fixed and re-verified. The harness report records the
  results in `magitech-harness/docs/conformance/e2e-live-report.md`.

## Version and compatibility

- `__version__`, package metadata, and the parity note now report `0.3.0`.
- The animas dependency is now `animas>=0.3,<0.4` (previously `>=0.1,<0.2`, which
  excluded animas 0.2.0 and broke wheel dependency resolution).
- Before 1.0, breaking changes remain permitted. From the 1.0 declaration
  onward, breaking changes go through the per-release upgrade guide.

## Verification

Full suite at 100% statement and branch coverage; lint, format, and strict
type checks green; CI green on all legs.

Unresolved questions: none.
